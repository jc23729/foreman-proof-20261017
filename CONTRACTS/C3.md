# C3 — CSV input for `report_cli.py`

Accept a CSV file as `--input`, detected by a `.csv` suffix.

## Behaviour

`tests/fixtures/jobs.csv`:

```csv
id,state,priority
J-03,done,3
J-01,queued,2
J-02,queued,1
J-04,blocked,4
```

`python3 report_cli.py --input tests/fixtures/jobs.csv` must print the same
text report as the JSON input:

```
# Job Status
Total: 4 | Done: 1 | Running: 0 | Queued: 2 | Blocked: 1
Next: J-02
```

`--json` and `--format markdown` must also work with CSV input.

Malformed CSV (missing header, unknown state, non-integer priority) must exit
non-zero with a short message on stderr.

## Acceptance

- `tests/test_report_csv.py` — new behaviour
- `tests/test_report_cli.py` — regression, JSON text mode still works

## Constraints

- Only `report_cli.py` may change. `job_report.py` must stay byte-identical.
- No new third-party dependencies (stdlib `csv` is fine).
- No file writes at runtime.
