# C4 — Quiet mode for `report_cli.py`

Add `--quiet` to `report_cli.py`.

## Behaviour

`python3 report_cli.py --input tests/fixtures/jobs.json --quiet` must print
exactly one line on stdout:

```
J-02
```

If there is no queued job, print `none`. Nothing else on stdout. Exit 0.

`--quiet` combined with `--json` must print the same single line (quiet wins).
Malformed input must still exit non-zero with a short message on stderr.

Default behaviour (no `--quiet`) must not change.

## Acceptance

- `tests/test_report_quiet.py` — new behaviour
- `tests/test_report_cli.py` — regression, default text mode

## Constraints

- Only `report_cli.py` may change. `job_report.py` must stay byte-identical.
- No new third-party dependencies.
- No file writes at runtime.
