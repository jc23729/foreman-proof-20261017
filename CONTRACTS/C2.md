# C2 — Markdown table output for `report_cli.py`

Add `--format {text,markdown}` to `report_cli.py` (default `text`).

## Behaviour

`python3 report_cli.py --input tests/fixtures/jobs.json --format markdown`
must print exactly these lines, in this order:

```
# Job Status

| Metric | Count |
| --- | --- |
| Total | 4 |
| Done | 1 |
| Running | 0 |
| Queued | 2 |
| Blocked | 1 |

Next: J-02
```

One blank line between the heading, the table and the `Next:` line. Counts
must reflect the input. `Next:` is the id of the highest-priority queued job,
or `none`.

`--format text` (or no flag) must keep the current output exactly.

## Acceptance

- `tests/test_report_markdown.py` — new behaviour
- `tests/test_report_json.py` — regression, C1 still works
- `tests/test_report_cli.py` — regression, text mode still works

## Constraints

- Only `report_cli.py` may change. `job_report.py` must stay byte-identical.
- No new third-party dependencies.
- No file writes at runtime.
